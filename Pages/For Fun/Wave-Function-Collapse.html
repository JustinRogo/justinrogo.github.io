How it works

Explore the original project
  1. 01

    Start with possible tiles

    Each cell starts with a set of possible tiles. Turn on Show possibilities to see the remaining options blended together.

  2. 02

    Choose a tile

    At each step, WFC picks a tile for the cell with the least uncertainty. Tile weights affect the odds.

  3. 03

    Check the neighbors

    Remove tiles that don’t fit the neighbors, then repeat. If a cell has no options left, start another attempt.
